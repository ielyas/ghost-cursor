First public release.

- Hides the cursor after a configurable idle delay, and brings it back the
  instant you move the mouse.
- A global keyboard shortcut toggles auto-hide from anywhere.
- Launch at login, a menu bar icon that reflects the current state, and a
  delay from 1 to 60 seconds.
- No permissions required, no telemetry, no data collected. The only network
  request is the update check you ask for.

Requires macOS 14 or later. Download `GhostCursor-1.0.0.dmg`, open it, and drag
GhostCursor to Applications.
